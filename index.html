Kostenlosen, auf dieses Repository beschränkten Token erstellen: github.com/settings/personal-access-tokens/new — Repository access: "Only select repositories" → FairValue, Permissions: "Contents" → Read and write. Wird nur in deinem Browser gespeichert, nie in dieses Repository committet.

Dein Browser unterstützt die Web Speech API nicht (or has no German voice installed). Try Chrome, Edge, or Safari.

Tipps für bessere Aussprache

  • Chrome / Edge usually have the best-sounding German voices ("Google Deutsch" or Microsoft neural voices) since they use online, cloud-quality speech synthesis.
  • Safari / macOS uses Apple's on-device German voices — good quality and works offline, but pick one explicitly in System Settings → Accessibility → Spoken Content → System Voice if only a low-quality default shows up here.
  • If no German voice appears in the dropdown, your OS may not have one installed — check your system's language/voice settings.
  • Still not natural enough? Switch to ElevenLabs above for noticeably more human-sounding German speech, using your own free API key.

Runs entirely in your browser — no text is uploaded anywhere.
